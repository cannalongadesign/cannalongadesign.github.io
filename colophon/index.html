Behind the site

Built to be read by people, and by the AI tools they ask

More and more recruiters ask an AI assistant about a candidate before they open a portfolio. This site is set up so that, when they do, the answer is correct and points back here.

Seven things make that work:

  1. The same me, everywhere

    My name, title and location are written exactly the same way here, on my résumé and on LinkedIn, and the pages tell search engines that these profiles belong to one person. That way an AI does not mix me up with someone else.

  2. A label for machines on every page

    Behind each page there is a small block of structured data, called JSON-LD, a standard format that search engines read. It says who I am, what each case is about and what it achieved. People never see it; search engines and AI tools rely on it.

  3. The answer comes first

    Every case starts with a short version: the problem, what I did and the result, with the numbers written as plain sentences. Anyone skimming, person or machine, gets the point in seconds.

  4. Works even without JavaScript

    All the English text is in the page itself; the EN/PT switch only swaps the language. Tools that do not run scripts read the same content you do.

  5. A summary written for AI

    llms.txt is a short plain-text summary of the site made for language models, and llms-full.txt has the full text of every case.

  6. AI search tools are welcome

    The site’s rules for crawlers explicitly let search engines and AI assistants read it, from OpenAI, Anthropic and Perplexity to Google, Apple and Microsoft, and a sitemap lists every page with its last update.

  7. Only numbers I can back up

    Every result says how it was measured, and anything I could not verify is left out. An AI repeats what it finds, so the page has to be right first.

It is the same principle as my product work: decide what the reader needs, then make it impossible to miss.
